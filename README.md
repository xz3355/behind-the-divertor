# Behind the Divertor

Mapping the human cost of fusion energy materials: where the tungsten in a fusion reactor's divertor comes from. Built with Sayari data for NYU's course **Beyond the Brand: Harnessing Emerging Tech in Ethical Sourcing** (Chelsea Zhao, November 2026).

## What's here

- `index.html`: the website (open it in a browser or view it on GitHub Pages). Section 6 is the **Proposed Regulation Simulator** added in Session 9.
- `CONCEPT-IDEA.md`: the concept for the simulator feature.
- `SPECIFICATIONS.md`: the simulator's data model, rule logic and acceptance checks.

## Note

The optical transceiver ban used in the simulator is reported, not law. US-content shares in the demo are illustrative assumptions; sources are listed on the page.
